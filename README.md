# NovoRise — Plateforme Moderne de Recrutement & Job Board

NovoRise est une plateforme web moderne et intuitive de mise en relation entre talents ambitieux et entreprises innovantes.

## ✨ Fonctionnalités

- **Moteur de recherche & filtres multi-critères** : Recherche en direct par intitulé, compétences clés et localisation.
- **Filtres avancés** : Par secteur d'activité (*Tech & IT*, *Marketing & Com*, *Vente & Business*, *Ingénierie & R&D*), type de contrat (*CDI*, *CDD*, *Freelance*, *Stage*) et modalité (*Remote*, *Hybride*, *Présentiel*).
- **Fiche détaillée de poste** : Modal contextuel affichant les missions clés, profil requis, avantages et rémunération indicative.
- **Candidature rapide en 1 clic** : Formulaire de candidature avec téléversement de CV et confirmation interactive.
- **Gestion des favoris** : Possibilité d'enregistrer ses offres préférées et de les retrouver facilement grâce au compteur d'en-tête.
- **Espaces dédiés** :
  - *Espace Candidats* : Dépôt de CV dans la CVthèque NovoRise.
  - *Espace Recruteurs* : Formulaire de diffusion d'offres en direct.
  - *Authentification* : Modale de connexion / inscription pour candidats et entreprises.
- **Design soigné & Responsive** : Conçu avec Tailwind CSS, palette de couleurs moderne, typographie épurée et compatibilité mobile/desktop totale.

## 🛠️ Stack Technique

- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (icônes)

## 🚀 Démarrage Rapide

### Prérequis
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation

```bash
# 1. Cloner le dépôt
git clone https://github.com/ycntrader-12/NovoRise.git
cd NovoRise

# 2. Installer les dépendances
npm install

# 3. Lancer le serveur de développement
npm run dev
```

L'application sera accessible sur [http://localhost:3000/](http://localhost:3000/).

### Build de Production

```bash
npm run build
```

Les fichiers optimisés seront générés dans le dossier `dist/`.
